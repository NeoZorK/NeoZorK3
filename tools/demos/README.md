# Demos

These scripts are illustrations only. They use randomly generated prices
(`random.uniform`) and simulated volumes, so they demonstrate no real market data,
no real arbitrage opportunities and no real profit. Some (`real_demo.py`,
`testnet_demo.py`) call public RPC endpoints, but the opportunity detection in them is
still simulated. They do not exercise the C++ bot, whose trading logic is a stub.

The repository is archived (2026-09-30); see the top-level `README.md`.
